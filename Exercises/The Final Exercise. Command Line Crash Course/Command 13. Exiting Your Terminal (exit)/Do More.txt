forfiles: show all files in a directory.

runas: run a program.

attrib: show files in directory.

icacls: Displays or modifies discretionary access
        control lists (DACLs) on specified files, 
        and applies stored DACLs to files in specified 
        directories.


forfiles example:

PS C:\Windows\System32> cd ~
PS C:\Users\Nayef> cd Downloads
PS C:\Users\Nayef\Downloads> forfiles
[ A list of folders ]
PS C:\Users\Nayef\Downloads>

runas example:
PS C:\Windows\System32> cd ~
PS C:\Users\Nayef> cd ../../
PS C:\> runas /user:NAYEF "Program Files\Audacity\Audacity.exe"
Enter the password for NAYEF:
Attempting to start Program Files\Audacity\Audacity.exe as user "NAYEF\NAYEF" ...
* A window pops up *
PS C:\Users\Nayef>

attrib example:
PS C:\Windows\System32> cd ~
PS C:\Users\Nayef> cd temp
PS C:\Users\Nayef\files> attrib
A                    C:\Users\Nayef\temp\files1.txt
A                    C:\Users\Nayef\temp\file2.txt
PS C:\Users\Nayef\temp>

icacls example:
PS C:\Windows\System32> cd ~
PS C:\Users\Nayef> cd temp
PS C:\Users\Nayef\temp> icacls *
