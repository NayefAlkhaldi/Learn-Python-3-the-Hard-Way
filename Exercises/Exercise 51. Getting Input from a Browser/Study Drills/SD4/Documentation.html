How to install and active Apache in Windows

Why Apache?

Apache is the most widely used web server software. Developed and maintained by Apache Software Foundation, Apache is an open source software available for free. It runs on 67% of all webservers in the world. It is fast, reliable, and secure. It can be highly customized to meet the needs of many different environments by using extensions and modules.

The setup

Step 1: Downloading Apache

Go to https://httpd.apache.org/. Under Essentials, click Download!

Under Apache HTTP Server 2.4.53 (httpd): 2.4.53 is the latest available version section, click on Files for Microsoft Windows. Next, Click on Apache lounge. After that, you'll see two versions of Apache, download what's compaitable with your operating system

Step 2: Install Visual C++ Redistributable Visual Studio.

To run the program correctly, you must be sure that you installed Visual C++ Redistributable Visual Studio. Go to https://www.apachelounge.com/download/. You'll see two versions: vc_redist_x64, vc_redist_x86. Download what's compaitable with your operating system.

Step 3: Extracting Files

The file should be downloaded now, so extract it, move the ( Apache24 ) folder to local disk (Visual C++ Redistributable Visual Studio too.)

× Warning! Do not move the entire file. You must onlly move Apache24 to local disk which is located in 'httpd-2.4.53-win64-VS16'.

Step 4: Adding the Command

Add a path to system environment variables to simulate a new command. Open file explorer, right click on This PC, Go to Properties -> Advanced. Click on the Environment Variables button below. In User variables, double click on path. Click Browse -> Go to C drive Apache24 folder -> Select bin folder -> Save changes. Now the command is active.

Save changes. The command now is accessible.

Step 5: Command Prompt

Open command prompt in administrator mode and type this:

On your browser, type ( localhost ) and hit enter. You should be able to see this message:

And now, close the server by typing (httpd.exe -k stop -n "Apache2.4") on command propmt.

Fixing Bugs:

Incorrect path:

Sometimes, the path may be incorrect. So all you have to do is to change httpd .conf file. Open the file, on line 37, change ( Define SRVROOT "/Apache24" ) to where Apache file is located

Port Number:

When you start Apache, make sure it's actully running:

If not, right click it and run it. If Apache still won't start, maybe there's a program on your pc is using port 80. That causes to stop Apache from running (Apache program use port 80). To fix that, you should make some changes to httpd.conf file ( The file located on C:\Apache24\conf\httpd.conf). Open the file, on line 60, change ( Listen 80 ) to (Listen *:80) (That tells Apache to listen to all ports) Save the file and close it.
